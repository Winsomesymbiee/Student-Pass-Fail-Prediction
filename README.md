# 🎓 Student Pass/Fail Prediction

A Machine Learning project developed in Python that predicts whether a student will **Pass** or **Fail** based on academic performance. The application uses the **Random Forest Classifier** algorithm and provides an easy-to-use graphical interface (GUI) built with Tkinter.

## 📌 Features

- Predicts student pass/fail status
- User-friendly Tkinter GUI
- Machine Learning using Random Forest
- Fast and accurate predictions
- Simple and easy to use

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn
- Tkinter

## 📂 Dataset Features

- Study Hours
- Attendance
- Previous Marks
- Assignments Completed

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Student-Pass-Fail-Prediction.git
```

Move into the project directory:

```bash
cd Student-Pass-Fail-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
